# AviaTicketSearchBot

Асинхронный Telegram-бот для поиска авиабилетов через реальные эндпоинты Aviasales / Travelpayouts API.

## Что внутри

- `aiogram 3.x` и `Router` для команд и сообщений.
- FSM (`FSMContext`) вместо `telebot.register_next_step_handler`.
- `aiohttp` вместо `requests` для всех HTTP-запросов к Travelpayouts.
- Поиск направления по IATA-коду, названию города или названию аэропорта:
  - `MOW`, `KZN`, `LED`;
  - `Москва`, `Казань`, `Санкт-Петербург`, `Сочи`, `Екатеринбург`;
  - `Пулково`, `Шереметьево`, `Домодедово`, `Кольцово`.
- Выбор локации кнопками, если название неоднозначное.
- Вопрос о количестве билетов перед поиском с проверкой положительного целого числа.
- Детальная выдача вариантов: аэропорты, дата/время, длительность, пересадки, авиакомпания, рейс, цена, валюта и ссылка.
- Реальные эндпоинты:
  - `/aviasales/v3/prices_for_dates` — несколько вариантов перелёта;
  - `/v1/prices/cheap` — fallback дешевых билетов;
  - `/v1/city-directions` — популярные направления;
  - `/v2/prices/calendar` — календарь цен;
  - `https://autocomplete.travelpayouts.com/places2` — поиск городов и аэропортов.
- Inline-кнопки через `InlineKeyboardBuilder`.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

```env
BOT_TOKEN=ваш_telegram_токен
TRAVELPAYOUTS_TOKEN=ваш_travelpayouts_токен
MARKER=ваш_маркер_если_есть
CURRENCY=rub
```

Запуск:

```bash
python main.py
```

## Команды

- `/start` — приветствие и кнопки быстрого запуска.
- `/help` — справка по формату ввода.
- `/search` — пошаговый поиск: откуда → куда → дата → количество билетов.
- `/popular` — популярные направления из выбранного города/аэропорта.
- `/cancel` — отмена текущего FSM-сценария.

## Новый сценарий поиска

1. Пользователь вводит `/search`.
2. Бот спрашивает город, аэропорт или IATA-код отправления.
3. Пользователь вводит, например, `Москва`.
4. Бот определяет IATA-код автоматически или предлагает варианты кнопками.
5. Бот спрашивает город, аэропорт или IATA-код прилёта.
6. Пользователь вводит, например, `Казань`.
7. Бот спрашивает дату вылета в формате `YYYY-MM-DD`.
8. Бот спрашивает: `Сколько билетов нужно?`.
9. Пользователь вводит положительное целое число.
10. Бот запрашивает API и показывает до 10 разных вариантов перелёта; если API вернул пять и более предложений, в выдаче будет минимум пять вариантов.

## Структура

```text
config.py                  # чтение переменных окружения
api.py                     # aiohttp-клиент Travelpayouts и запросы билетов
main.py                    # Bot, Dispatcher, подключение Router-ов
handlers/start.py          # /start, /help, /cancel и кнопки меню
handlers/search.py         # FSM поиска, выбор локаций, популярные направления
services/locations.py      # поиск городов/аэропортов и fallback-словарь
states/search_states.py    # состояния TicketSearchState и PopularDirectionState
keyboards/inline.py        # InlineKeyboardBuilder-клавиатуры
utils/validators.py        # проверка названий, дат и количества билетов
utils/formatters.py        # форматирование детальной выдачи билетов
```
