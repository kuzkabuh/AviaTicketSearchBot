# Новостной модуль

Новостной модуль автоматически собирает новости и акции авиакомпаний через `NewsScheduler`.

## Источники

Подключены официальные HTML/press источники для:

- Аэрофлот (`SU`)
- Победа (`DP`)
- Россия (`FV`)
- S7 Airlines (`S7`)
- Уральские авиалинии (`U6`)
- Utair (`UT`)
- Nordwind Airlines (`N4`)
- Smartavia (`5N`)
- Red Wings (`WZ`)
- Азимут (`A4`)
- Аврора (`HZ`)
- NordStar (`Y7`)
- Ямал (`YC`)
- Якутия (`R3`)
- ИрАэро (`IO`)
- ЮВТ Аэро (`RT`)
- Qatar Airways (`QR`)
- Emirates (`EK`)

В реестре авиакомпаний также есть перевозчики, требующие ручной настройки источника: Pegas Fly/Икар, РусЛайн, Алроса, Северсталь Авиа и другие, если официальный раздел нестабилен или не имеет надёжной публичной ленты.

## Health-check

Для каждого источника хранятся `health_status`, `consecutive_errors`, `last_checked_at`, `last_success_at`, `last_error_at`, `last_error_message`. После 3 ошибок подряд создаётся admin alert с cooldown, а при успешной проверке alert переводится в resolved.

## Модерация

Новые записи создаются со статусом `pending`. Администратор видит карточку, источник, авиакомпанию, категорию, маршрут, промокод и ссылку; публикация переводит новость в пользовательскую выдачу.
