# Административные уведомления

Централизованный сервис: `services/admin_alerts_service.py`.

Таблица истории: `admin_alerts_history`.

Реализовано:

- dedup/cooldown по `(alert_type, alert_key)`;
- active/resolved state;
- уведомления о новых новостях на модерации;
- уведомления о сломанных источниках новостей после серии ошибок;
- уведомление о восстановлении источника;
- уведомление об ошибке обновления;
- helper для ошибки миграции;
- база для API/digest alerts через `send_alert`.

Если `bot` или `ADMIN_IDS` недоступны, alert записывается в БД и логируется, но не отправляется в Telegram.
